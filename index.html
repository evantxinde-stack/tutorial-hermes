1. Apa itu Hermes Agent?

Hermes Agent adalah AI assistant pribadi berbasis agen (agentic AI) yang dikembangkan oleh Nous Research. Berbeda dengan chatbot biasa yang hanya menjawab pertanyaan, Hermes Agent bisa:

  • 🤖 Menggunakan tools — menjalankan terminal, membaca file, browsing web, mengirim pesan
  • ⏰ Bekerja terjadwal — menjalankan tugas otomatis via cron jobs
  • 🧠 Memiliki memori — mengingat preferensi dan konteks antar sesi
  • 🔌 Terintegrasi — Telegram, WhatsApp, Discord, API server
  • 🎓 Belajar dari pengalaman — menyimpan skill dan pengetahuan baru

Intinya: Hermes bukan sekadar "chatbot yang jawab pertanyaan", tapi asisten digital yang bisa bertindak — mengeksekusi perintah, mengelola file, dan menjalankan automasi.

3. Instalasi

3.1 Installer Resmi (Linux/macOS)

curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash

3.2 Via pip (Python 3.10+)

pip install hermes-agent  # atau: pipx install hermes-agent

3.3 Verifikasi Instalasi

hermes --version
hermes doctor   # cek kesehatan instalasi
💡 Tip: Hermes membutuhkan Python 3.10+. Jika belum ada, install dulu via sudo apt install python3.11 python3-pip (Ubuntu/Debian).

4. Setup Awal & Konfigurasi

4.1 Setup Interaktif

hermes setup

Wizard ini akan memandu: pilih provider AI, model default, dan konfigurasi dasar lainnya.

4.2 Konfigurasi Manual (config.yaml)

# File: ~/.hermes/config.yaml
model:
  provider: anthropic          # atau: openai, google, openrouter, custom
  model: claude-sonnet-4-5     # model default
  api_key: sk-xxx              # API key provider

telegram:
  enabled: true
  bot_token: 123456:ABC-DEF    # token bot dari @BotFather
  chat_id: 123456789           # chat ID tujuan

4.3 Set Konfigurasi via CLI

hermes config set model.provider openai
hermes config set model.model gpt-4o
hermes config set telegram.enabled true
hermes config get model   # lihat konfigurasi saat ini

5. Cara Menggunakan

5.1 CLI Chat

hermes chat          # mulai sesi chat interaktif
hermes chat -q "Halo, apa kabar?"   # one-shot query
hermes chat --resume  # lanjutkan sesi sebelumnya

5.2 Commands Penting

6. Otomasi dengan Cron Jobs

Salah satu fitur paling powerful — Hermes bisa menjalankan tugas terjadwal otomatis:

6.1 Membuat Cron Job

hermes cron add --schedule "0 7 * * *" --prompt "Buat briefing berita pagi hari ini" --name "daily-briefing"

6.2 Format Schedule (Cron Expression)

ExpressionArti
0 7 * * *Setiap hari jam 07:00
*/30 * * * *Setiap 30 menit
0 9 * * 1-5Senin-Jumat jam 09:00
0 0 1 * *Tanggal 1 setiap bulan jam 00:00
every 2hSetiap 2 jam (format manusiawi)
30mSetiap 30 menit (format sederhana)

6.3 Manage Cron Jobs

hermes cron list      # lihat semua job
hermes cron pause <job_id>  # pause job
hermes cron resume <job_id> # lanjutkan job
hermes cron remove <job_id> # hapus job
hermes cron run <job_id>    # jalankan manual sekarang
💡 Ide otomasi: briefing berita pagi, monitor harga crypto, laporan kesehatan, backup file, reminder jadwal, dan banyak lagi!

7. Mengganti AI Provider

Hermes mendukung banyak provider AI. Kamu bisa switch kapan saja:

7.1 Provider Resmi

ProviderSet viaContoh Model
AnthropicANTHROPIC_API_KEYclaude-sonnet-4-5
OpenAIOPENAI_API_KEYgpt-4o, gpt-5
GoogleGOOGLE_API_KEYgemini-2.5-pro
OpenRouterOPENROUTER_API_KEYRatusan model dari berbagai vendor

7.2 Custom Endpoint (OpenAI-compatible)

Bisa pakai server LLM sendiri (Ollama, vLLM, LM Studio) atau AI router seperti 9Router:

hermes config set model.provider custom
hermes config set model.base_url http://localhost:20128/v1
hermes config set model.api_key 9r-xxxx
hermes config set model.default kr/claude-sonnet-4.5
💡 Hemat budget: Kombinasi AI router (seperti 9Router) + provider gratis bisa membuat biaya AI harian mendekati nol.

8. Integrasi Telegram

8.1 Buat Bot Telegram

  1. Buka Telegram, chat @BotFather
  2. Kirim /newbot, ikuti instruksi, dapatkan bot token
  3. Buat grup/chat, tambahkan bot, kirim pesan ke bot

8.2 Konfigurasi di Hermes

hermes config set telegram.enabled true
hermes config set telegram.bot_token 123456789:AAH-xxxx

8.3 Fitur Telegram

  • 💬 Chat dengan AI langsung dari Telegram
  • 🔔 Notifikasi hasil cron jobs otomatis
  • 📁 Kirim & terima file
  • 👥 Support group chat (dengan mode topic)
⚠️ Penting: Jika bot tidak membalas di grup, cek Privacy Mode di @BotFather → /setprivacy → Disable. Ini penyebab paling umum bot diam di grup!

9. Tips & Best Practices

  • 🧠 Gunakan memory — simpan preferensi agar AI tidak perlu ditanya ulang
  • 🎯 Buat skill — untuk tugas berulang, buat skill khusus daripada prompt panjang
  • ⏰ Otomasi dulu, mikir belakangan — mulai dari 1-2 cron job yang paling sering kamu butuhkan
  • 💰 Kelola budget — pantau penggunaan API, gunakan model murah untuk tugas sederhana
  • 🔐 Amankan API keys — jangan commit ke git publik, gunakan environment variables
  • 📊 Pantau dengan dashboard — gunakan hermes dashboard untuk lihat usage
  • 🔄 Update rutin — pip install -U hermes-agent untuk versi terbaru

10. Studi Kasus

📰 Studi Kasus 1: Content Creator — Automasi Konten Harian

Latar belakang: Seorang content creator Instagram perlu posting 2x sehari (pagi & sore) dengan konten yang konsisten dan relevan.

Solusi Hermes:

  • 📝 Cron job pagi (07:00): Generate ide konten + caption berdasarkan tren terbaru
  • 🖼️ Cron job sore (19:00): Generate deskripsi + hashtag untuk visual yang sudah dibuat
  • 🧠 Memory: Menyimpan brand voice, tone, dan preferensi gaya konten
  • 🎯 Skill khusus: Carousel image generator + caption template

Hasil: Produksi konten 2x lipat dengan effort manual 70% lebih rendah. Semua draft otomatis sampai ke Telegram untuk review sebelum posting.

💼 Studi Kasus 2: Digital Marketer — Monitoring Brand & Kompetitor

Latar belakang: Seorang digital marketer perlu memantau berita, mention brand, dan aktivitas kompetitor setiap hari.

Solusi Hermes:

  • 🔍 Cron job tiap 2 jam: Search web & social media untuk mention brand + kompetitor
  • 📊 Auto-summarize: Hermes merangkum berita penting jadi 3-5 poin singkat
  • 📬 Deliver via Telegram: Ringkasan dikirim otomatis ke grup tim
  • 🧠 Learning loop: Hermes belajar keywords penting dari sesi ke sesi

Hasil: Tim selalu up-to-date tanpa manual scrolling. Waktu monitoring turun dari 2 jam/hari menjadi 10 menit review.

💪 Studi Kasus 3: Personal Health Coach — Reminder & Tracking

Latar belakang: Seseorang ingin konsisten dengan target kesehatan (berat badan, olahraga, tidur).

Solusi Hermes:

  • ⏰ Cron jobs terjadwal: Reminder bangun pagi (06:30), sarapan (07:00), olahraga (07:30), napas malam (20:30), tidur (22:15)
  • 📝 Check-in mingguan: Hermes tanya berat badan & progres, simpan di memori
  • 🍳 Konteks personal: Hermes ingat preferensi diet (contoh: vegetarian, target kalori) dan sesuaikan saran
  • 💬 Interaktif: User bisa reply langsung ke reminder untuk update kondisi

Hasil: Konsistensi naik signifikan karena reminder datang otomatis di waktu yang tepat, dengan pesan yang personal bukan template.

🛠️ Studi Kasus 4: Developer — Automasi Coding Tasks

Latar belakang: Developer sibuk dengan banyak repo dan PR review.

Solusi Hermes + coding agents:

  • 🤖 Delegasi coding: Hermes melempar tugas ke Codex/OpenCode/Claude Code CLI
  • 🔀 Parallel worktrees: Banyak task dikerjakan paralel di worktree terpisah
  • 👀 PR review otomatis: Hermes clone repo, review PR, kirim komentar via gh CLI
  • 🧭 Knowledge graph: Graphify memetakan codebase besar jadi graph yang bisa di-query

Hasil: Developer fokus ke arsitektur & keputusan penting, kerjaan repetitif didelegasikan ke agent.

11. FAQ — Pertanyaan yang Sering Diajukan

❓ Apakah Hermes Agent gratis?

Hermes Agent-nya sendiri open source & gratis (MIT license). Yang berbayar adalah API model AI yang kamu gunakan (OpenAI, Anthropic, dll). Tapi ada banyak opsi gratis: model open-source lokal (Ollama), provider gratis, atau AI router dengan akses model gratis.

❓ Apa bedanya Hermes Agent dengan ChatGPT?

ChatGPT adalah chatbot di website — kamu ketik, dia jawab. Hermes adalah agen yang bisa bertindak: menjalankan perintah terminal, mengelola file, browsing, dan menjalankan tugas otomatis terjadwal. Hermes juga punya memori persisten dan bisa dideploy di server sendiri.

❓ Berapa biaya menjalankan Hermes?

Biaya = biaya API model yang dipakai. Contoh: dengan model hemat + kombinasi provider gratis, biaya bisa di bawah $5-10/bulan. Model open-source lokal bisa nol rupiah (hanya butuh listrik).

❓ Bisakah Hermes dipakai di HP?

Bisa! Melalui Telegram (paling populer), WhatsApp, atau web workspace. Kamu deploy Hermes di server/VPS, lalu akses dari mana saja via HP.

❓ Apakah Hermes bisa dipakai banyak orang sekaligus?

Bisa — lewat gateway API server, Hermes melayani banyak pengguna (multi-user). Cocok untuk tim kecil. Setiap user bisa punya chat/session sendiri.

❓ Data saya aman tidak?

Kamu kontrol sendiri server & datanya. Hermes self-hosted = data tidak keluar dari server kecuali request ke API model. Kamu bisa pilih model lokal (Ollama) agar data 100% di server sendiri.

❓ Model AI apa yang bisa dipakai?

Hampir semua: Claude (Anthropic), GPT (OpenAI), Gemini (Google), DeepSeek, Qwen, Llama lokal, dan ratusan model via OpenRouter atau AI router lainnya. Bahkan bisa ganti model di tengah percakapan.

❓ Apakah Hermes bisa membaca file saya?

Ya — dengan izinmu, Hermes bisa membaca & mengedit file di server, menjalankan script, dan mengelola repository. Semua aksi tercatat dan bisa diawasi.

❓ Apa itu "Skill" di Hermes?

Skill = pengetahuan prosedural yang bisa dipasang/dibuat. Contoh: skill riset pasar, skill health coach, skill bikin carousel. Skill membuat Hermes ahli di domain spesifik tanpa perlu dijelaskan ulang.

❓ Bagaimana kalau terjadi error?

Mulai dari hermes doctor untuk diagnosa. Cek log di ~/.hermes/logs/. Mayoritas masalah umum punya solusi yang terdokumentasi — lihat tabel troubleshooting di bawah.

❓ Bisakah Hermes dipakai untuk trading?

Bisa — banyak user membuat cron job monitoring harga crypto/saham, berita pasar, dan analisis. Disclaimer: keputusan trading tetap tanggung jawabmu, AI hanya alat bantu analisis.

❓ Apakah perlu bisa coding untuk pakai Hermes?

Tidak wajib. Fitur dasar (chat, cron jobs, Telegram) bisa dipakai tanpa coding — semua lewat command sederhana atau config. Kemampuan coding membuatmu bisa custom lebih dalam, tapi bukan prasyarat.

13. Hermes Workspace — Web Control Center

Hermes Workspace adalah web UI lengkap buat ngatur Hermes Agent langsung dari browser — chat, terminal, memory, skills, jobs, sampai MCP, semua nyatu dalam satu dashboard. Gak perlu bolak-balik buka terminal; cukup browser, dan seluruh agent lo bisa dikendalikan dari satu tempat.

⚡ Fitur Utama

  • 💬 Chat SSE streaming — respons real-time kayak ngetik di chat biasa
  • 🖥️ Terminal web — jalanin command langsung dari browser
  • 🧠 Memory editor — lihat & edit memori agent secara visual
  • 📚 Skills browser — jelajah 2000+ skill yang tersedia
  • 🔌 MCP page — kelola Model Context Protocol (MCP) servers
  • 📊 Dashboard — pantau sessions, model mix, dan cost
  • 👁️ Agent View — lihat aktivitas agent secara real-time
  • 🌊 Swarm Mode — control plane buat banyak agent sekaligus
  • 📋 TaskBoard (kanban) — atur tugas agent ala kanban board
  • 🖥️ TUI view — tampilan terminal buat yang kangen CLI
  • 📱 PWA — bisa di-install kayak app native di HP

🛠️ Cara Akses

Workspace terdiri dari 3 komponen yang jalan bareng:

hermes gateway run    # API gateway — port :8642
hermes dashboard    # dashboard UI — port :9119
pnpm dev            # workspace frontend — port :3000

Buat pairing ketiganya, set variabel ini di file .env:

HERMES_API_URL=http://localhost:8642
HERMES_DASHBOARD_URL=http://localhost:9119

📱 Akses dari HP

Workspace bisa diakses dari HP via Cloudflare tunnel, Tailscale, atau LAN — dan karena ini PWA, lo bisa install langsung kayak app di home screen HP. Ngatur agent dari mana aja, kapan aja.

🌊 Highlight: Swarm Mode

Swarm Mode ngubah Workspace jadi control plane buat unlimited Hermes Agents dengan 1 orchestrator. Agent-agent jalan di atas tmux-backed workers, tugas di-dispatch per role, dan hasilnya di-track lewat kanban. Cocok banget buat lo yang mau menjalankan banyak agent dengan pembagian peran yang jelas.

14. Bot Mode — Tim AI Agent

Bot Mode ngubah profile Hermes jadi "Bot" — tiap bot punya role, model, memory, skills, dan avatar sendiri. Bot-bot ini bisa jalanin rutinitas, diskusi di group chat, sampai saling kirim pesan satu sama lain. Intinya: lo punya tim AI agent yang kerja bareng.

🧩 Konsep Inti

  • Bot = Hermes profile — config, memory, skills, dan chat tiap bot ter-isolasi di ~/.hermes/profiles/<nama>/
  • Bot Mode = UI di atas profile — cara ngatur & ngobrol sama bot-bot itu
  • Semua bot juga visible di CLI — bukan cuma di UI

✨ Fitur

  1. Roster bot + avatar — blob face, geometric, upload gambar sendiri, AI-generated, atau pet
  2. Bot chat canonical — riwayat persisten; /new di-reroute ke /compact biar konteks gak ilang
  3. Bot-to-bot messaging — pake @mention atau message_agent(target=...); bot nyusun pesannya sendiri lengkap dengan atribusi
  4. Group chats — 2–6 bot diskusi, maksimal 3 ronde, @mention buat scope pembicaraan, escalate ke @user kalau perlu
  5. Routines — jadwal per bot via cron namespaced [bot:<nama>]
  6. Create on — pilih device tempat bot jalan (multi-connection)
  7. hermes peer — bot lintas gateway bisa saling DM

🤖 Cara Bikin Bot

Via Hermes Desktop: buka tab Bots → New Agent → isi Nama / Title / Description. Di bagian Advanced lo bisa clone profile, pin model, set SOUL.md, dan pilih skills.

Via CLI:

hermes profile create <nama> --clone

💼 Use Case: Tim Digital Marketing

Bayangin lo bikin bot-bot dengan peran spesifik — research bot, copy bot, creative bot, ads bot, finance bot, dan CRM bot — masing-masing pake skill & model sendiri, lalu mereka diskusi di group chat buat nyusun campaign. Tiap bot fokus di bidangnya, hasilnya lebih rapi dan terukur.

⚙️ Konfigurasi

agent.bot_mode_protocol: true   # aktifkan Bot Mode (default)
