Hermes Ads Agent

Terakhir diperbarui: 30 Agustus 2026

1. Pendahuluan

"Hermes Ads Agent" adalah aplikasi internal milik pemilik akun, digunakan khusus untuk mengelola dan mengoptimalkan iklan Meta Ads pada akun milik pemilik aplikasi sendiri.

2. Data yang Dikumpulkan

Aplikasi ini TIDAK mengumpulkan, menyimpan, atau memproses data pribadi pengguna akhir. Aplikasi hanya mengakses data iklan milik pemilik akun (campaign, ad set, ad, dan insight) melalui Meta Marketing API, atas izin eksplisit dari pemilik akun.

3. Penggunaan Data

Data iklan yang diakses digunakan semata-mata untuk otomatisasi pembuatan, pengujian, dan optimasi iklan pada akun milik sendiri. Data tidak dijual, disewakan, atau dibagikan kepada pihak ketiga mana pun.

4. Penyimpanan & Penghapusan

Token akses API disimpan di perangkat lokal pemilik akun dengan akses terbatas, dan dapat dicabut kapan saja melalui Meta Business Manager. Log aktivitas lokal dapat dihapus kapan saja atas permintaan pemilik akun.

5. Berbagi Data

Satu-satunya pihak yang menerima data adalah Meta Platforms, sebagai penyedia platform tempat akun iklan berada, sesuai dengan Kebijakan Data Meta.

6. Keamanan

Token API disimpan dengan akses terbatas dan dirotasi secara berkala. Akses ke aplikasi hanya dimiliki oleh pemilik akun.
